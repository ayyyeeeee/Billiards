# 学习曲线批处理

双击实验总目录中的 **绘制学习曲线.cmd**，或本工具文件夹中的 **start.cmd**，打开绘图窗口。

1. 实验总目录默认是本工具文件夹的上一级，也就是 `D:\experiment`。
2. 输入受试者编号，如 `01`、`01,02,04` 或 `01-05`。输入 `1` 也可识别为 `01`。
3. 点击“绘制输入编号”，或直接点击“绘制全部受试者”。
4. 点击“打开输出文件夹”查看结果。

不需要输入训练条件或实际球数。程序按文件名识别 baseline、training、test，以及 both、strength、angle。

## 输出

结果保存在实验总目录下的 `learning_curves` 文件夹：

- `01.png`：全英文六面板高清图片。
- `01.svg`：可缩放矢量图片。
- `statistics/01.json`：实际球数、分块结果、前后均值和源文件校验信息。
- `batch_report.json`：最近一次批次的成功、失败与数据提示。

其他受试者同样按编号命名。重复运行会更新同编号的图片。原始 CSV 不会被修改。

## 数据目录与命名

优先读取非空的 `MOLT4_results_v3/csv/`；尚未重算 v3 时兼容下列旧版结构。不同版本不混合：

```
实验总目录/01/MOLT4_results/csv/*.csv
实验总目录/01/MOLT4/_results/csv/*.csv
```

例如 `01_04_training_both_140shots.csv`。文件名中的 `140shots` 仅用于核对，**实际统计始终使用 CSV 内的数据行**。

旧版 CSV 使用 `shot` 和 `value`。新版 both 使用 `shot`、`strength_value` 和 `angle_value`，允许原来的 `value` 为空。单条件 strength/angle 如果有对应分量列，优先读取该列；否则兼容旧 `value`。

新版使用每个分量自己的 `strength_maximum` / `angle_maximum` 判断封顶；复合 `unit` 如 `strength:origin_to_strip;angle:degree` 会分别解析。程序不依据 `needs_review` 排除记录或添加特殊标记。

每位受试者应有一个 training 文件。both、strength、angle 的 baseline/test 各一个；缺少其中某个阶段时会在图中说明。相同阶段、相同条件有多个文件时会报错，避免不明确地合并。某位受试者失败不会阻止同批其他人绘图。

## 六面板与统计约定

- a：自动识别训练条件的逐球表现与分块均值。
- b：训练分块的样本标准差。
- c：训练分块中达到记录上限的比例。
- d–f：both、strength、angle 各自的 baseline 与 test。

**新版 both 双分量：** 当 training=both 时，a、b、c 面板内分别上下展示 strength 与 angle 两个分量。无论训练条件是什么，d 面板中的 both baseline/test 都展示两部分。每个分量有独立纵轴与单位；同一 both 文件的两个分量不与独立 strength/angle 条件的数据混合，也不会被重复计入总击球数。e、f 仍展示独立 strength/angle 条件。

新版图中 `n = scored/recorded` 表示已评分数 / 实际记录数。例如 `n = 9/10` 表示该块 10 次击球中，这个分量有 9 个有效分数。

默认每 10 条实际记录为一个连续、不重叠区块。先按 shot 排序，保留全部记录位置；shot 有间隔时不填补数据。两个 both 分量使用相同分块边界，各自仅用已有分数计算均值与标准差。`unresolved` 空分数不填零，也不删除另一分量的有效数值。最后不足 10 球的区块照常显示。只有 1 个分数时可计算均值，但不计算标准差；整块无分数时均值与标准差均留空。

缺少一个分量列、同条件 baseline/test 混用新旧指标结构、重复 shot 或无效非空数值会报错，避免误配。旧版单值 both 保持原来的绘法，不凭空推算两个分量。

Baseline 使用该条件全部实际记录作为参照。Test 按实际记录分块，显示每块 shot 范围及 n。不同条件不混合统计。每个条件使用自身尺度，距离指标保留原始 recorded units，CSV 单位为 degree 时显示 degrees。

误差棒表示均值 ± 1 个样本标准差，不是置信区间。所有记录正常参与统计，没有复核特殊标记或排除虚线。封顶判断允许 CSV 数值舍入误差；maximum 缺失时该球不进入封顶比例的分母，元数据不足会在面板中说明。

曲线是描述性分块曲线，未做显著性检验。即时且有反馈的 test 可以描述前后变化、可能的迁移和 test 内的变化，但不能单独证明长期保持或因果效应。

## 可选命令行

```
python learning_curves.py 01
python learning_curves.py 01 02 04
python learning_curves.py 01-05
python learning_curves.py --all
python learning_curves.py 04 --block-size 10
python learning_curves.py 01 --root D:\experiment --output D:\experiment\learning_curves
```

日常使用不需要命令行。已将当前 Windows Python 3.12 所需绘图库放入工具自己的 `.deps`，不依赖之前的示范图目录。启动器优先使用当前电脑的 Codex Python，找不到时尝试系统 Python。移动实验数据时可以在窗口选择新总目录。迁移到另一台电脑需有兼容的 Windows Python 3.12（含 tkinter）；不要只复制 start.cmd，应复制整个工具文件夹。
